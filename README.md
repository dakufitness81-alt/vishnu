# Vishnu AutoPilot 🤖

An AI agent that **generates content ideas, produces vertical short videos, and
publishes them to your social media accounts — automatically.**

```
 ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌──────────────────────────────┐
 │  IDEAS  │ → │ SCRIPT  │ → │  VIDEO  │ → │          PUBLISH             │
 │ 7 viral │   │ hook +  │   │ 1080×1920│ → │ local · youtube · tiktok · x │
 │ formats │   │ 4 tips  │   │ H.264    │   │ facebook · instagram         │
 └─────────┘   └─────────┘   └─────────┘   └──────────────────────────────┘
        idea keys recorded in state.json → no idea is ever repeated
```

One command runs the whole thing:

```bash
python -m agent run
```

**Works 100% free and offline by default** — a built-in idea/script engine and
caption-style video renderer need zero API keys. Add keys to `.env` to upgrade
the writing (LLM), add a voiceover (OpenAI TTS), and connect real accounts to
publish.

---

## Quickstart

```bash
cd vishnu
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt

./.venv/bin/python -m agent run          # idea → video → saved post
./.venv/bin/python -m agent status       # posting history
```

The finished post (video, caption, metadata) lands in `output/published/<id>/`.
Watch the video in `output/posts/<id>/video.mp4`.

### Make it yours (2 minutes)

1. `config.yaml` → set `agent.handle` to your real handle, pick a `niche`
   (fitness · tech · finance · cooking · travel · general — or add your own
   in `agent/ideas.py`).
2. `.env` (create with `python -m agent init`) → leave empty to stay offline,
   or add keys per the table below.
3. `python -m agent run --platforms local` to preview; then add real platforms.

## Commands

| Command | What it does |
|---|---|
| `python -m agent run` | Full pipeline, once. (default when no command given) |
| `python -m agent run --idea "My idea"` | Use your own idea |
| `python -m agent run --platforms youtube,x --count 2` | Post 2 videos to YouTube + X |
| `python -m agent run --dry-run` | Never touches real platforms |
| `python -m agent ideas --count 5` | Just print generated ideas |
| `python -m agent video --idea "..."` | Render a video without publishing |
| `python -m agent publish <dir> --platforms x` | Re-publish an existing bundle |
| `python -m agent loop --interval 86400` | **Daemon**: post daily, forever |
| `python -m agent loop --interval 3600 --count 6` | Post hourly, 6 times |
| `python -m agent status` | What was posted and where |
| `python -m agent auth x` / `auth youtube` | Interactive OAuth setup |
| `python -m agent init` | Create `.env` from the template |

## How each part works

### 1 · Ideas (`agent/ideas.py`)
Seven content formats (listicle, myth-bust, story, mistake, debate, beginner,
wish-list) combined with per-niche word banks. Seeded by date + posting
history, so ideas vary day to day and **never repeat** (tracked in
`state.json`). With an LLM key set, ideas are generated by the model instead.

### 2 · Script (`agent/scripts.py`)
Hook + 4 tip beats + CTA. The offline engine is deterministic per idea (same
idea → same script, so re-renders are stable). With an LLM key, the model
writes custom beats.

### 3 · Video (`agent/video.py`)
Renders 1080×1920 slides (hook → numbered tips with progress bar → CTA) using
PIL, over AI-generated background art in `assets/` (falls back to gradients).
Encodes H.264 MP4 with the bundled `imageio-ffmpeg` binary — no system
ffmpeg needed. Slide durations scale to the voiceover length when audio
exists. Typical output: ~25 s, ~2 MB.

### 4 · Voice (`agent/voice.py`)
`auto` = OpenAI TTS if a key is set → espeak-ng if installed → silent
(captions carry the message).

### 5 · Publish (`agent/publishers/`)
| Platform | Env vars / setup | Notes |
|---|---|---|
| `local` | none | Dry-run: saves the post to `output/published/` |
| `youtube` | `YOUTUBE_CLIENT_SECRET_JSON` + `python -m agent auth youtube` | Vertical <60 s auto-qualifies for Shorts. Needs `pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib` |
| `x` | `X_CLIENT_ID` + `X_CLIENT_SECRET` + `python -m agent auth x` | OAuth 2.0 PKCE flow, token cached in `secrets/`. Videos auto-shrunk to X's 5 MB limit |
| `tiktok` | `TIKTOK_CLIENT_KEY` + `TIKTOK_CLIENT_SECRET` | Requires an approved TikTok developer app (Content Posting API) |
| `facebook` | `FACEBOOK_PAGE_ID` + `FACEBOOK_PAGE_TOKEN` | Video post to a Page |
| `instagram` | `INSTAGRAM_BUSINESS_ACCOUNT_ID` + `INSTAGRAM_ACCESS_TOKEN` | Published as a Reel (business account linked to the Page) |

### 6 · State (`agent/state.py`)
`state.json` stores every accepted post (idea key, platforms, timestamp).
Failed runs are **not** recorded, so the next run retries naturally.

## Connecting your accounts

All credentials live in `.env` (git-ignored) or `secrets/` (git-ignored).
Nothing is ever committed.

**X (Twitter)** — create an app at [developer.x.com](https://developer.x.com)
with OAuth redirect `http://localhost:8080/callback`, fill `X_CLIENT_ID` /
`X_CLIENT_SECRET` in `.env`, then run `python -m agent auth x` and paste the
code from the redirect. Free tier allows limited monthly posts.

**YouTube** — Google Cloud Console → create project → enable *YouTube Data
API v3* → OAuth consent (External, testing) → Credentials → OAuth client ID
(Desktop app) → download JSON → set `YOUTUBE_CLIENT_SECRET_JSON` to its path
→ `python -m agent auth youtube`. Optional: `YOUTUBE_PRIVACY=unlisted`.

**Facebook / Instagram** — create a Meta app with the *Instagram Basic* /
*Instagram Graph API* products, generate a Page access token with
`pages_manage_posts` (Facebook) and a token with `instagram_content_publish`
for your business account (Instagram).

**TikTok** — register at [developers.tiktok.com](https://developers.tiktok.com)
and request Content Posting API access (approved apps only).

## Running it automatically

**Option A — built-in daemon:**

```bash
nohup ./.venv/bin/python -m agent loop --interval 86400 >> autopilot.log 2>&1 &
```

**Option B — cron** (one post per day at 07:30):

```cron
30 7 * * * cd /home/user/vishnu && ./.venv/bin/python -m agent run >> autopilot.log 2>&1
```

Every run picks a fresh idea, so a daily cron gives you a daily video with no
repeats.

## Free vs. upgraded

| Capability | Without keys (default) | With keys |
|---|---|---|
| Ideas | offline engine, 7 formats, niche banks | LLM-generated, fully custom |
| Script | deterministic tips per niche | LLM-written beats |
| Voiceover | silent (caption-driven — standard for Shorts) | OpenAI TTS (5 voices) |
| Video | ✅ full 1080×1920 H.264 | ✅ same |
| Publishing | `local` dry-run | YouTube / X / TikTok / FB / IG |

Add `OPENAI_API_KEY` (or `OPENROUTER_API_KEY`) to `.env` to enable the LLM
writing and TTS — the agent detects it automatically and falls back to the
offline engine if a call fails.

## Responsible use

- Respect each platform's terms and rate limits (X's free tier, for example,
  allows only a small number of posts per month).
- Start with `--dry-run` / the `local` publisher and check the first few
  videos yourself.
- New TikTok apps typically start with posts in a private review queue.
- The agent posts only what you configure in `config.yaml` — no hidden
  accounts, no third-party data collection.
